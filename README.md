## Pages
Static HTML pages use folder-based URLs, for example `/about/` and `/services/computer-repairs/`.
The shared static mega-menu is included in each page's HTML. Without a build system, update navigation markup on every page when changing it.

## Deployment
1. Commit the project to your GitHub repository.
2. In GitHub repository Settings → Pages, select the correct publishing branch and root folder.
3. Configure the custom domain `www.it-u.co.za`.
4. Set up DNS records with your domain provider and enable HTTPS when available.
5. Replace the Google and Bing verification placeholders with genuine verification tokens.
6. Check canonical URLs, navigation, images, forms and mobile layouts after deployment.

## SEO
- `robots.txt` permits crawling and points to `sitemap.xml`.
- `sitemap.xml` lists public pages intended for indexing.
- Each HTML page includes a unique title, description, canonical URL and social metadata.
- Keep sitemap entries aligned with pages that exist and return successful responses.

## Important notes
- Root-relative links are configured for the custom domain. If testing through `https://itusolutions.github.io/iT-U-Projects/`, configure a repository base path or use a suitable relative-path strategy.
- The contact form is a demo that opens an email draft; it does not submit to a server.
